How to play Roll a color, then tap that snail to move it one square. Every snail gets to finish.

The voices behind the race

Snails: Grace, age 4. Die: Olivia, age 3. Referee: Scott. The original artwork and recordings are preserved from the Java game.

Turn rules off for free play: roll or move any snail whenever you like. With rules on, roll first and move the matching snail. If that snail has finished, tap it to complete the turn.

Originally written in C, then C++, and ported to Java in 1996. Based on Ravensburger’s Snail’s Pace Race board game.
