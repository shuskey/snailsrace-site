# Neon artwork

Six transparent PNG snail sprites were generated separately with the built-in image-generation tool. Dice and decorative neon-tube snail motifs are project-native SVG artwork. Original generated PNGs are copied unchanged into this directory.

## Final generation prompt set

Each sprite uses the following prompt, replacing `{color}` with the corresponding description below:

> Use case: stylized-concept. Asset type: single transparent PNG game sprite for a children's 2D racing game called Snail's Race, Neon theme. Create exactly ONE cute smiling snail facing RIGHT in side view. Full body and antennae visible, large round spiral shell occupying left-center, low smooth rounded foot extending to the right, two friendly large white eyes with black pupils on stalks at the right, tiny happy smile. Style: polished soft 3D cartoon with bright airbrushed shading, glossy highlights and a restrained neon rim glow. Color: {color}; both body and shell must clearly belong to this one color family, shell spiral a darker shade of the same color. Keep white eyes. No multicolor rainbow shell. Composition: square canvas, snail centered and filling 85% of width and 75% of height, equal padding, horizontally oriented, ground contact at 85% canvas height. Background genuinely transparent including corners; no scene, no platform, no text, no watermark, no extra objects. Clear readable silhouette when scaled to 64 pixels.
